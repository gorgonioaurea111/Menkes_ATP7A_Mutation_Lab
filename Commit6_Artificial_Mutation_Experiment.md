# Commit 6 — Artificial Mutation Experiment

## Disease and Gene

- Disease: Menkes disease
- Gene: ATP7A
- Reference transcript: NM_000052.7
- Reference protein: NP_000043.4

## Artificial Mutation

For the second experiment, a single-nucleotide substitution was introduced into the ATP7A wild-type CDS.

| Feature | Result |
|---|---|
| Mutation type | Single-nucleotide substitution |
| Original codon | AGT |
| Mutant codon | AGA |
| Nucleotide change | T → A |
| Original amino acid | Serine (S) |
| Mutant amino acid | Arginine (R) |
| Protein change | S4R |
| Mutation type at protein level | Missense |
| CDS length | 4,503 bp |
| Reading frame | +1; no change |
| Protein length | 1,500 aa |
| First amino-acid difference | Position 4: S → R |
| Premature stop codon | No |

## Mutation Prediction

Because only one nucleotide was changed, the reading frame was expected to remain unchanged. The substitution was predicted to produce a missense mutation because the altered codon specifies a different amino acid.

The expected sequence-level change was:

**AGT → AGA → Serine (S) → Arginine (R)**

## Translation Results

The artificial mutant sequence was translated using the same reading frame as the wild-type sequence.

The translated protein remained **1,500 amino acids long** and did not contain a premature stop codon. The first amino-acid difference occurred at **position 4**, where serine was replaced by arginine.

## Interpretation

The artificial mutation demonstrates how a single-nucleotide substitution can change one amino acid without changing the reading frame or overall protein length.

The sequence analysis supports:

**T → A nucleotide substitution → AGT-to-AGA codon change → S4R amino-acid substitution**

Unlike the documented G727R mutation, the artificial S4R mutation was created computationally in this experiment. Therefore, any effect on ATP7A structure or function is a prediction and should not be considered experimentally demonstrated.

## Conclusion

The artificial S4R mutation produced a single amino-acid substitution while maintaining the original reading frame and 1,500-amino-acid protein length. No premature stop codon was produced.
