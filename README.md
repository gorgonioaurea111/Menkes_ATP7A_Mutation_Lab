## II. Project Overview

This laboratory project investigates the relationship between gene
mutations and disease using Menkes disease as the selected genetic
disorder.

The project focuses on the ATP7A gene, which encodes a copper-
transporting ATPase involved in maintaining copper homeostasis.

The documented variant investigated is c.2179G>A, resulting in the
amino acid substitution p.Gly727Arg (G727R).

The project includes the analysis of the wild-type ATP7A coding
sequence and protein, the documented mutant sequence and protein,
and an artificial missense mutation created for comparison.

## V. Documented Mutation

The documented mutation analyzed in this project is:

**NM_000052.7(ATP7A):c.2179G>A (p.Gly727Arg)**

The nucleotide substitution changes the codon GGA to AGA,
resulting in the replacement of glycine with arginine at amino
acid position 727.

This is a missense single-nucleotide variant. It does not cause
a frameshift or change the overall length of the protein.

The documented variant is associated with Menkes disease and
has published evidence concerning ATP7A protein stability and
copper transport.

## VI. Artificial Mutation

An artificial missense mutation was created for the laboratory
exercise.

- Original codon: AGT
- Mutated codon: AGA
- Nucleotide change: T>A
- Amino acid substitution: Serine to arginine
- Protein notation: p.Ser4Arg (S4R)

The artificial mutation is used for sequence comparison and
computational analysis. It is not presented as a documented
disease-causing ATP7A variant.

Its functional effects have not been experimentally established
in this laboratory exercise.
