Cell and Molecular Biology Laboratory

Disease: Menkes disease
Gene: ATP7A
Documented mutation: c.2179G>A (p.Gly727Arg; G727R)
Reference transcript: NM_000052.7
Reference protein: NP_000043.4

Project Overview

This repository contains the sequence analysis of the ATP7A gene associated with Menkes disease.

The project investigates the relationship between a documented gene mutation, its effect on the protein sequence, and the possible molecular consequences. It also includes a student-created artificial mutation for comparison.

Project Contents

The project will document:

- WT ATP7A reference CDS and protein
- Menkes disease and normal ATP7A function
- Documented ATP7A mutation
- Mutant protein analysis
- Artificial mutation experiment
- Comparison and interpretation of mutation results
- Final laboratory report
